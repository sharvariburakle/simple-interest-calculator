# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple tool used to calculate the interest earned or paid on a principal amount over a specific period of time.

## Formula

Simple Interest (SI) = (P × R × T) / 100

Where:
- **P (Principal):** Initial amount of money.
- **R (Rate):** Annual rate of interest in percentage.
- **T (Time):** Time period in years.

## Example

Suppose:
- Principal = 10,000
- Rate of Interest = 5%
- Time = 2 years

Calculation:

SI = (10,000 × 5 × 2) / 100

**Simple Interest = 1,000**

## Features
- Calculates simple interest.
- Uses principal, rate, and time as inputs.
- Easy to understand and use.
- Provides quick and accurate results.

## Output
The calculator displays the calculated simple interest based on the provided inputs.
